| **Priority / Severity** | **High Severity**                                                                                                                            | **Low Severity**                                                                                           |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **High Priority**       | Key features failed and no workaround. <br> *E.g.* Login button is not working.                                                              | Basic feature failed but it has a huge impact on customer’s business. <br> *E.g.* Misspelled Company logo. |
| **Low Priority**        | Key features failed but no impact on customer’s business. <br> *E.g.* Calculation fault in yearly report which end user won’t use regularly. | Cosmetic issues. <br> *E.g.* Font family mismatch in a report.                                             |
