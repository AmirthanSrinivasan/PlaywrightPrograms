1. Install Node.js → https://nodejs.org

2. Create project folder and initialize:

npm init -y

3. Install Playwright:

npm install -D @playwright/test

4. Install browsers (Chromium, Firefox, WebKit):

npx playwright install

5. (Optional) Install Allure or other reporters if you need reports.

✅ After this, you can run a test:

npx playwright test
